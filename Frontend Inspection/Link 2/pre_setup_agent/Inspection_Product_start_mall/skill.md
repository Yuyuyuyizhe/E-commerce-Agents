本 skill 只负责从抖音商城页搜索指定关键词，并进入商品搜索列表。

## 执行规则

1. 本 skill 的起点应为抖音首页或可返回到首页的页面
2. 如当前不在首页，可使用 `mobile_back` 返回，直到可以执行搜索
3. 点击上方商城标签
4. 点击商城标签下方搜索栏
5. 输入指定关键词
6. 点击搜索栏右侧搜索按钮执行搜索，核实当前页面搜索结果不为空，如果结果为空则进入第7步，不为空直接跳转到第8步
7. 如果搜索结果为空：
    7.1 立即使用 `mobile_back` 返回，直到返回到抖音首页，点击右上搜索
    7.2 输入指定关键词
    7.3 点击搜索栏右侧搜索按钮执行搜索
8. 点击“商品”选项，切换商品搜索详情页
9. 如果下方列出的商品不是一行一个，那么点击搜索正下方第二行，筛选按钮边上的四个正方形图标，切换到一行一个的模式，以看到更多的商品标题信息
10. 点击第一行的商品，进入第一个商品的商品详情页

## 完成标准
- 当前页面已进入商品详情页
- 能看到搜索结果列表，且商品展示一行一个
