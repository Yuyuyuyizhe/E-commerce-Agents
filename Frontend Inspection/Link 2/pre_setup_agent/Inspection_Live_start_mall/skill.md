# 巡检进入首个直播间

本 skill 只负责从抖音商城页搜索指定关键词，并进入直播列表中的第一个直播间。

## 执行规则

1. 本 skill 的起点应为抖音首页或可返回到首页的页面
2. 如当前不在首页，可使用 `mobile_back` 返回，直到可以执行搜索
3. 点击上方商城标签
4. 点击商城标签下方搜索栏
5. 输入指定关键词
6. 点击搜索栏右侧搜索按钮执行搜索，核实当前页面搜索结果不为空，如果结果为空则进入第7步，不为空直接跳转到第8步
7. 如果搜索结果为空:
  7.1 立即使用 `mobile_back` 返回，直到返回到抖音首页，点击右上搜索
  7.2 输入指定关键词
  7.3 点击搜索栏右侧搜索按钮执行搜索
8. 点击“直播”选项，切换到直播列表
9. 点击第一个直播间的展示区域进入直播间
10. 进入直播间后立即结束，不执行任何额外操作
11. 除最终结束外，不输出任何过程性 content

## 完成标准

- 当前页面已进入直播间
- 直播画面基本占据整个屏幕
- 看不到搜索输入栏或搜索结果列表
