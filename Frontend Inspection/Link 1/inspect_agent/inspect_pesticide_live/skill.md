# 农药虚假宣传巡检

用于单个直播间 case 的最终判定。一次只审核一个直播间。

本 skill 不负责切换直播间，只负责在当前可审核直播间内获取信息并完成最终判定。

## 适用前置条件

- 已经先执行过 `Live_Inspection_Precheck`
- 当前页面已经是一个可继续审核的直播间
- 当前直播间处于直播间主页，且页面可见“分享”按钮

如果以上条件未满足，不要调用本 skill。

#### 审核目标

识别“农药”专项领域的直播间是否存在“虚假宣传”违规行为。

## 标准执行步骤

### 第 1 步：获取全局信息

- 调用 `mobile_get_live_room_id` 获取当前直播间 id

### 第 2 步：调用ez_agent获取判断结果

- 拿到直播 id 后，调用 `call_ez_agent(agent_code=c_end_inspection_pesticide_live, params={"room_id":{直播id}})`
- 读取ez_agent的返回结果

## 输出要求

整理完成后，直接返回固定格式结果：

开始时间--是否违规--理由--直播id--违规商品id--挂车商品ID列表

字段要求如下：
- `开始时间`：填写当前 case 切片的开始时间
- `直播id`：填写当前 case 的直播 id
- `是否违规`：填写“违规”或“不违规”
- `理由`：
  - 违规时，填写“已检测到农药虚假宣传”
  - 不违规时，可填写“未检测到农药虚假宣传”
- `违规商品id`：
  - 违规时填写对应商品 id
  - 无法确认或不违规时填写 `None`
- `挂车商品ID列表`：
  - 从ez_agent的返回结果中提取前8个商品id，若不满足8个则提取全部
  - 若无法提取，填写 `None`
